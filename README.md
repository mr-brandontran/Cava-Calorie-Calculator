# CAVA Calorie & Nutrition Calculator 🥗

A responsive, high-performance Mediterranean nutrition calculator and macro tracker for CAVA, styled after Chipotle's clean corporate tabular design system and optimized for mobile & iPhone.

## ✨ Features
- **Official CAVA Nutrition Guide Data:** Accurate calories, protein, carbs, fat, saturated fat, sodium, fiber, and sugars for all menu items.
- **Smart Assembly Line Rules:**
  - Automatic 50/50 base splits (e.g. Brown Rice + Super Greens).
  - 3-dip inclusion tracking.
  - Portion modifiers: Normal (1x), Double (2x), Light (0.5x), and On Side.
- **Authentic Slide-up FDA Nutrition Facts Panel:** Real-time % Daily Values with one-tap order copying for MyFitnessPal / macro tracking.
- **Dietary & Allergen Filtering:** One-tap filtering for Vegan, Vegetarian, Gluten-Free (Wheat), Dairy-Free (Milk), Soy-Free, Egg-Free, and Sesame-Free.
- **Chef-Curated Recipes:** Browse and inspect official recipes for Curated Bowls & Pitas.
- **Mobile First:** iOS safe-area support, thumb-friendly sticky dock, and tabular numeral alignment.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
